Name by Gander Predictior

This is a simple python program that predicts if a name is Male or Female using machine learning.

Features: 
* Shows dataset info
* Train a model (KNN or Decision Tree)
* Test the model and see accuracy
* Predict gender from a new name
* Option to save result to a file


Dataset
The program uses a CSV file like this: 

  Name      Gender  
  Anna      Female
  James     Male

Filename: gender_by_name.csv

How to run the code:

Download or clone the project.

git> Clone: https://github.com/rinhaz/NamebyGender---rr
pip install pandas scikit-learn
python gender.py
